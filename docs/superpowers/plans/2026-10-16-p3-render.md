# P3: Render — VideoSpec → MP4 via HyperFrames — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a `VideoSpec` (our frame-based IR) renders deterministically and offline to an MP4 through HyperFrames. The MP4 contains:
- generated plates, with the **real product cutout composited on top** under one shared motion;
- b-roll video;
- word-by-word burned-in captions (Latin and Devanagari);
- an on-screen claim;
- voice audio.

It is stored in AdForge storage as an internal `MediaRef`.

**Architecture:**
- **`packages/core`** gains the `VideoSpec` Zod schema (frames are the source of truth) and the `RendererProvider` type.
- **`packages/renderer-hyperframes`** turns a spec into a HyperFrames project:
  - `compose.ts` is a pure `VideoSpec → index.html` (GSAP timeline, timed clips, local fonts);
  - `stage.ts` copies assets, GSAP and fonts into a temp project dir, so render needs no network;
  - `render.ts` runs `createRenderJob` / `executeRenderJob` with an abort deadline, stores the MP4, then drains the browser pool and deletes the project dir.

**Tech Stack:**
- `@hyperframes/producer` and `@hyperframes/engine` **0.8.106** (exact; published 2026-10-01). The internal `@hyperframes/*` packages are pinned to 0.8.106 via pnpm `overrides`.
- `gsap` 3.15.0 (vendored into each render project).
- `@fontsource/inter` 5.3.0 and `@fontsource/noto-sans-devanagari` 5.3.0.
- Puppeteer's `chrome-headless-shell`.
- FFmpeg (Gyan full build via winget).
- Zod 4, Vitest 5.

**Spec:** [docs/superpowers/specs/2026-10-15-adforge-local-poc-design.md](../specs/2026-10-15-adforge-local-poc-design.md), including §11. **Roadmap:** [2026-10-16-p3-p8-roadmap.md](2026-10-16-p3-p8-roadmap.md), the P3 section plus the liveness rule.

## Global Constraints

- All timing in **frames** in our code. Seconds appear only in the generated HTML, converted in exactly one function (`secs()` in `compose.ts`).
- **Layers reference storage keys** (`MediaRef.id`, shape `^[0-9a-f]{2}/[0-9a-f]{64}\.[a-z0-9]+$`), never URLs. The renderer resolves keys through `StorageProvider`.
- **The renderer receives our `VideoSpec`, never provider-shaped JSON.**
- HyperFrames determinism contract:
  - no wall clock, no live network at render time, no unseeded randomness, no `repeat: -1`;
  - GSAP and fonts are loaded from **local files** in the project dir;
  - every `<audio>` has an `id`;
  - no `crossorigin`;
  - no `<video data-start>` inside another element with `data-start`;
  - no CSS `transform` on an element that GSAP also tweens.
- **Pin exact versions; nothing newer than 2 weeks** (pnpm's release-age gate stays on). Versions live in the `catalog:` block. `@hyperframes/*` transitive packages are pinned via `overrides`.
- **Liveness:**
  - every render has a deadline (`renderTimeoutMs`, default 15 min) through `executeRenderJob(..., abortSignal)`, and a timeout becomes `ProviderError('TIMEOUT')`;
  - the browser pool is drained after every render, success or failure;
  - the temp project dir is removed after every render.
- Fonts must resolve before render, or text renders as tofu: Inter (Latin) and Noto Sans Devanagari (Hindi), each with a local `@font-face`.
- Never let a video model render the hero product: the cutout is a real-pixel overlay.
- `pnpm test` (typecheck first) must pass before every commit. Functional tests per task. **One end-to-end check at the end of the plan** (`pnpm e2e:render`).
- Commits: `git -c user.name=heetshah16 -c user.email=shahheet85@gmail.com commit ...` with a `Co-Authored-By:` trailer naming the authoring model.

## Review Focus

1. **Frame/second boundary drift.** A 600-frame spec must render exactly 600 frames, and frame *n* must show scene *k*'s content exactly when the spec says so. → Task 2: the boundary simulation test, and Task 4: the frame count via ffprobe.
2. **Devanagari captions render as tofu.** Hindi words need the Devanagari font face. → Task 2: golden HTML includes both `@font-face` rules and the font stack; Task 3: the staged font files exist.
3. **A missing asset key.** It must fail **before** Chrome launches, naming the key, not produce a black frame. → Task 3 test.
4. **A hung or slow render.** It must abort at the deadline, return a retryable `TIMEOUT`, and leave no Chrome running and no temp dir behind. → Task 4 test.
5. **User text containing `<`, `&` or quotes in captions or overlays.** It must be escaped, never break the HTML. → Task 2 test.

import { z } from 'zod';
import { Motion } from '../vocab/enums';

/** Our IR. Frames are the source of truth; layers reference storage keys, never URLs. */
export const StorageKey = z.string().regex(/^[0-9a-f]{2}\/[0-9a-f]{64}\.[a-z0-9]+$/, 'expected a storage key');
const Frame = z.number().int().nonnegative();
const PositiveFrames = z.number().int().positive();
const Frac = z.number().min(0).max(1);
const Hex = z.string().regex(/^#[0-9a-fA-F]{6}$/);

export const TextPosition = z.enum(['top_third', 'mid_lower', 'bottom_center']);
export type TextPosition = z.infer<typeof TextPosition>;
export const TextWeight = z.enum(['regular', 'bold', 'chunky']);
export type TextWeight = z.infer<typeof TextWeight>;

const PlateLayer = z.object({ type: z.literal('plate'), key: StorageKey });
/** Real product pixels (T0). Anchored by its bottom-centre point, as fractions of the frame. */
const CutoutLayer = z.object({
  type: z.literal('cutout'),
  key: StorageKey,
  anchorX: Frac,
  anchorY: Frac,
  heightFrac: z.number().gt(0).max(1),
  shadow: z.boolean(),
});
/** Fills its scene; trimStartFrame is the offset into the source clip. */
const VideoLayer = z.object({ type: z.literal('video'), key: StorageKey, trimStartFrame: Frame });
const TextLayer = z.object({
  type: z.literal('text'),
  content: z.string().min(1).max(60),
  position: TextPosition,
  weight: TextWeight,
  scrim: z.boolean(),
});
export const Layer = z.discriminatedUnion('type', [PlateLayer, CutoutLayer, VideoLayer, TextLayer]);
export type Layer = z.infer<typeof Layer>;

export const Scene = z.object({
  startFrame: Frame,
  durationInFrames: PositiveFrames,
  /** Applied identically to the plate and the cutout so the product stays locked to the scene. */
  motion: Motion,
  layers: z.array(Layer).min(1),
});
export type Scene = z.infer<typeof Scene>;

const Word = z.object({ text: z.string().min(1).max(40), startFrame: Frame, endFrame: Frame });

export const VideoSpec = z
  .object({
    id: z.string().min(1),
    width: PositiveFrames,
    height: PositiveFrames,
    fps: z.literal(30),
    durationInFrames: PositiveFrames,
    theme: z.object({ primary: Hex, accent: Hex }),
    scenes: z.array(Scene).min(1),
    audio: z.object({
      voice: z.array(z.object({ key: StorageKey, startFrame: Frame, durationInFrames: PositiveFrames })),
    }),
    captions: z.object({ position: TextPosition, words: z.array(Word) }),
  })
  .superRefine((s, ctx) => {
    const issue = (message: string) => ctx.addIssue({ code: 'custom', message });

    let cursor = 0;
    for (const [i, scene] of s.scenes.entries()) {
      if (scene.startFrame !== cursor) issue(`scenes must be contiguous from frame 0: scene ${i} starts at ${scene.startFrame}, expected ${cursor}`);
      cursor = scene.startFrame + scene.durationInFrames;

      const bg = scene.layers[0]?.type;
      if (bg !== 'plate' && bg !== 'video') issue(`scene ${i}: first layer must be a plate or video background`);
      const videos = scene.layers.filter((l) => l.type === 'video').length;
      const plates = scene.layers.filter((l) => l.type === 'plate').length;
      if (videos > 1 || (videos === 1 && plates > 0)) issue(`scene ${i}: at most one video layer, and never together with a plate`);
    }
    if (cursor !== s.durationInFrames) issue(`scene durations sum to ${cursor}, expected durationInFrames ${s.durationInFrames}`);

    for (const [i, v] of s.audio.voice.entries()) {
      if (v.startFrame + v.durationInFrames > s.durationInFrames) issue(`voice track ${i} ends after the video`);
    }

    let prevEnd = 0;
    for (const [i, w] of s.captions.words.entries()) {
      if (w.endFrame <= w.startFrame) issue(`caption word ${i} has no duration`);
      if (w.startFrame < prevEnd) issue(`caption word ${i} overlaps the previous word`);
      if (w.endFrame > s.durationInFrames) issue(`caption word ${i} ends after the video`);
      prevEnd = w.endFrame;
    }
  });
export type VideoSpec = z.infer<typeof VideoSpec>;
```

# HyperFrames — provider reference

**Fetched:** 2026-10-16 from the HyperFrames source (v0.8.91 checkout in the Claude plugin cache: `packages/producer`, `packages/engine`, `skills/hyperframes-core`). **Pinned version:** `@hyperframes/producer` / `@hyperframes/engine` **0.8.106**.

## Programmatic render
- `createRenderJob(config)` → `RenderJob`. Required: `fps` (`{ num: 30, den: 1 }` or a number) and `quality` (`'draft' | 'standard' | 'high'`). Optional: `format` (default `'mp4'`), `workers`, `crf`, `strictness`, `entryFile` (default `index.html`), `logger`.
- `executeRenderJob(job, projectDir, outputPath, onProgress?, abortSignal?)` → `Promise<void>`. On return, `job.status` / `job.error` / `job.failedStage` describe the outcome.
- `drainBrowserPool()` / `closeBrowserPool()` from `@hyperframes/engine` close pooled Chrome.
- **Frame count:** `totalFrames = ceil(rootDurationSeconds × fps)`.

## Environment
- **FFmpeg / FFprobe:** found on `PATH`, or via `HYPERFRAMES_FFMPEG_PATH`.
- **Chrome:** `chrome-headless-shell`. The engine looks in this order:
  1. `PRODUCER_HEADLESS_SHELL_PATH`;
  2. `HYPERFRAMES_BROWSER_PATH`;
  3. `~/.cache/hyperframes/chrome/chrome-headless-shell`;
  4. `~/.cache/puppeteer/chrome-headless-shell` (installed by puppeteer's postinstall).
- **On Windows** capture uses screenshot mode. BeginFrame is Linux-only.

## Composition contract (what AdForge's `compose.ts` relies on)
- **Standalone `index.html` root:** `<div id="root" data-composition-id="…" data-width data-height data-duration>`, with no `<template>`. The root uses `width/height: 100%`; the canvas size comes from `data-width` and `data-height`.
- **Root `data-duration`** (seconds) is the render length. It is read once at compile time.
- **Clips:** any element with `data-start` (seconds), plus `data-duration`. Visibility is half-open: `[start, start+duration)`. Direct children of the root get `position:absolute; top:0; left:0`. `class="clip"` is a convention.
- **One paused GSAP timeline**, registered as `window.__timelines["<composition-id>"]`.
- **Media:**
  - `<video id muted playsinline data-start data-duration data-media-start>` must not be inside another `data-start` element.
  - `<audio id src data-start data-duration data-volume>`. **`id` is required, or the audio is silent.**
  - No `crossorigin`.
- **Determinism:** no wall clock, no network, no unseeded random, no `repeat:-1`. Fonts need an in-file `@font-face` pointing to a local file.
- **Lint traps:**
  - a CSS `transform` plus a GSAP tween on the same node (`gsap_css_transform_conflict`);
  - tweening `visibility`/`autoAlpha` on a `.clip`;
  - an `<audio>` without an `id`;
  - a `<video data-start>` inside a timed wrapper.
```

import type { Motion } from '@adforge/core/vocab/enums';

/**
 * GSAP source for one scene's motion. Applied to the stage wrapper, so the plate and the
 * real cutout move together. Finite and deterministic (no repeat:-1, no randomness).
 */
export function motionTween(target: string, motion: Motion, startSec: string, durationSec: string): string {
  const t = JSON.stringify(target);
  const base = `duration: ${durationSec}, ease: "none"`;
  switch (motion) {
    case 'static':
      return '';
    case 'slow_zoom_in':
      return `tl.fromTo(${t}, { scale: 1 }, { scale: 1.08, ${base} }, ${startSec});\n`;
    case 'slow_zoom_out':
      return `tl.fromTo(${t}, { scale: 1.08 }, { scale: 1, ${base} }, ${startSec});\n`;
    case 'slow_pan':
      return `tl.fromTo(${t}, { scale: 1.08, xPercent: -3 }, { scale: 1.08, xPercent: 3, ${base} }, ${startSec});\n`;
    case 'subtle_shake': {
      const step = 0.25;
      const repeats = Math.max(0, Math.floor(Number(durationSec) / step) - 1);
      return (
        `tl.set(${t}, { scale: 1.04 }, ${startSec});\n` +
        `tl.fromTo(${t}, { x: -4, y: 3 }, { x: 4, y: -3, duration: ${step}, ease: "sine.inOut", yoyo: true, repeat: ${repeats} }, ${startSec});\n`
      );
    }
  }
}

/** The ONLY frame→seconds conversion. Floors to whole µs: frame n (sampled at n/fps) always lands inside its window. */
export function secs(frame: number, fps: number): string {
  return (Math.floor((frame / fps) * 1e6) / 1e6).toFixed(6);
}
const span = (start: number, frames: number, fps: number) => ({
  start: secs(start, fps),
  duration: (Number(secs(start + frames, fps)) - Number(secs(start, fps))).toFixed(6),
});

function sceneLayers(scene: Scene, i: number): string {
  const parts: string[] = [];
  const stage: string[] = [];
  for (const layer of scene.layers) {
    switch (layer.type) {
      case 'plate':
        stage.push(`<img class="plate" src="${assetPath(layer.key)}" alt="">`);
        break;
      case 'cutout':
        stage.push(
          `<img class="cutout${layer.shadow ? ' shadow' : ''}" src="${assetPath(layer.key)}" alt="" ` +
            `style="left: ${(layer.anchorX * 100).toFixed(3)}%; top: ${(layer.anchorY * 100).toFixed(3)}%; height: ${(layer.heightFrac * 100).toFixed(3)}%;">`,
        );
        break;
      case 'text':
        parts.push(
          `<div class="overlay pos-${layer.position} w-${layer.weight}${layer.scrim ? ' scrim' : ''}">${esc(layer.content)}</div>`,
        );
        break;
      case 'video':
        break; // emitted at the root (a <video data-start> may not sit inside a timed wrapper)
    }
  }
  const stageHtml = stage.length ? `<div id="s${i}-stage" class="stage">${stage.join('')}</div>` : '';
  return stageHtml + parts.join('');
}

const videoOf = (scene: Scene) => scene.layers.find((l): l is Extract<Layer, { type: 'video' }> => l.type === 'video');

export function composeHtml(spec: VideoSpec): string {
  const { fps } = spec;
  const body: string[] = [];
  const tweens: string[] = [];

  spec.scenes.forEach((scene, i) => {
    const t = span(scene.startFrame, scene.durationInFrames, fps);
    const video = videoOf(scene);
    if (video) {
      body.push(
        `<video id="s${i}-video" class="clip" src="${assetPath(video.key)}" muted playsinline data-start="${t.start}" data-duration="${t.duration}" data-media-start="${secs(video.trimStartFrame, fps)}"></video>`,
      );
    }
    body.push(`<section id="s${i}" class="clip" data-start="${t.start}" data-duration="${t.duration}">${sceneLayers(scene, i)}</section>`);
    if (scene.layers.some((l) => l.type === 'plate' || l.type === 'cutout')) {
      tweens.push(motionTween(`#s${i}-stage`, scene.motion, t.start, t.duration));
    }
  });

  spec.audio.voice.forEach((v, i) => {
    const t = span(v.startFrame, v.durationInFrames, fps);
    body.push(`<audio id="vo${i}" src="${assetPath(v.key)}" data-start="${t.start}" data-duration="${t.duration}" data-volume="1"></audio>`);
  });

  spec.captions.words.forEach((w, i) => {
    const t = span(w.startFrame, w.endFrame - w.startFrame, fps);
    body.push(
      `<div id="w${i}" class="clip cap pos-${spec.captions.position}" data-start="${t.start}" data-duration="${t.duration}"><span>${esc(w.text)}</span></div>`,
    );
  });

  return `<!doctype html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=${spec.width}, height=${spec.height}">
<title>${esc(spec.id)}</title>
<script src="assets/gsap.min.js"></script>
<style>
${css(spec)}
</style>
</head>
<body>
<div id="root" data-composition-id="${COMPOSITION_ID}" data-start="0" data-width="${spec.width}" data-height="${spec.height}" data-duration="${secs(spec.durationInFrames, fps)}">
${body.join('\n')}
</div>
<script>
const tl = gsap.timeline({ paused: true });
${tweens.join('')}window.__timelines["${COMPOSITION_ID}"] = tl;
</script>
</body>
</html>
`;
}

const crcTable = Array.from({ length: 256 }, (_, n) => {
  let c = n;
  for (let k = 0; k < 8; k++) c = c & 1 ? 0xedb88320 ^ (c >>> 1) : c >>> 1;
  return c >>> 0;
});
const crc32 = (b: Uint8Array) => {
  let c = 0xffffffff;
  for (const x of b) c = crcTable[(c ^ x) & 0xff]! ^ (c >>> 8);
  return (c ^ 0xffffffff) >>> 0;
};
function chunk(type: string, data: Uint8Array): Buffer {
  const head = Buffer.alloc(8);
  head.writeUInt32BE(data.length, 0);
  head.write(type, 4, 'ascii');
  const crc = Buffer.alloc(4);
  crc.writeUInt32BE(crc32(Buffer.concat([head.subarray(4), data])), 0);
  return Buffer.concat([head, data, crc]);
}

/** A real, decodable RGB PNG of one colour. */
export function solidPng(w: number, h: number, rgb: [number, number, number]): Uint8Array {
  const ihdr = Buffer.alloc(13);
  ihdr.writeUInt32BE(w, 0);
  ihdr.writeUInt32BE(h, 4);
  ihdr.set([8, 2, 0, 0, 0], 8);
  const row = Buffer.alloc(1 + w * 3);
  for (let x = 0; x < w; x++) row.set(rgb, 1 + x * 3);
  const raw = Buffer.concat(Array.from({ length: h }, () => row));
  return Buffer.concat([
    Buffer.from([137, 80, 78, 71, 13, 10, 26, 10]),
    chunk('IHDR', ihdr),
    chunk('IDAT', deflateSync(raw)),
    chunk('IEND', new Uint8Array()),
  ]);
}

/** 16-bit mono 24 kHz PCM WAV of silence. */
export function silentWav(seconds: number): Uint8Array {
  const rate = 24000;
  const samples = Math.round(seconds * rate);
  const b = Buffer.alloc(44 + samples * 2);
  b.write('RIFF', 0);
  b.writeUInt32LE(36 + samples * 2, 4);
  b.write('WAVEfmt ', 8);
  b.writeUInt32LE(16, 16);
  b.writeUInt16LE(1, 20);
  b.writeUInt16LE(1, 22);
  b.writeUInt32LE(rate, 24);
  b.writeUInt32LE(rate * 2, 28);
  b.writeUInt16LE(2, 32);
  b.writeUInt16LE(16, 34);
  b.write('data', 36);
  b.writeUInt32LE(samples * 2, 40);
  return b;
}

export function tmpStorage() {
  const root = mkdtempSync(join(tmpdir(), 'adforge-render-'));
  return { root, storage: new LocalDiskStorage(join(root, 'media'), 'http://localhost:3000') };

import { copyFile, mkdir, writeFile } from 'node:fs/promises';
import { createRequire } from 'node:module';
import { dirname, join } from 'node:path';
import type { StorageProvider } from '@adforge/core/providers/types';
import type { VideoSpec } from '@adforge/core/spec/video-spec';
import { FONT_FILES } from './compose';

const require = createRequire(import.meta.url);

export function specKeys(spec: VideoSpec): string[] {
  const keys = new Set<string>();
  for (const scene of spec.scenes) for (const l of scene.layers) if ('key' in l) keys.add(l.key);
  for (const v of spec.audio.voice) keys.add(v.key);
  return [...keys];
}

/** Everything the composition references, copied locally: render needs no network and no storage access. */
export async function stageProject(spec: VideoSpec, storage: StorageProvider, dir: string): Promise<void> {
  // Read everything first, so a missing key fails before anything is written.
  const assets: [string, Uint8Array][] = [];
  for (const key of specKeys(spec)) {
    try {
      assets.push([key, await storage.read(key)]);
    } catch (e) {
      throw new Error(`Render asset missing from storage: ${key} (${(e as Error).message})`);
    }
  }

  await mkdir(join(dir, 'assets', 'fonts'), { recursive: true });
  for (const [key, bytes] of assets) await writeFile(join(dir, 'assets', key.slice(3)), bytes);
  await copyFile(require.resolve('gsap/dist/gsap.min.js'), join(dir, 'assets', 'gsap.min.js'));
  for (const f of FONT_FILES) {
    const pkgDir = dirname(require.resolve(`${f.pkg}/package.json`));
    await copyFile(join(pkgDir, f.src), join(dir, 'assets', 'fonts', f.file));
  }
}

import { mkdir, mkdtemp, readFile, rm, stat, writeFile } from 'node:fs/promises';
import { join } from 'node:path';
import { drainBrowserPool } from '@hyperframes/engine';
import { createRenderJob, executeRenderJob } from '@hyperframes/producer';
import {
  ProviderError,
  isRetryable,
  type MediaRef,
  type ProviderResult,
  type RenderRequest,
  type RendererProvider,
  type StorageProvider,
} from '@adforge/core/providers/types';
import { VideoSpec } from '@adforge/core/spec/video-spec';
import { composeHtml } from './compose';
import { stageProject } from './stage';

const P = 'hyperframes';

export interface HyperframesOptions {
  storage: StorageProvider;
  /** Parent dir for per-render temp projects. Keep it outside OneDrive (e.g. <ADFORGE_DATA_DIR>/render-work). */
  workDir: string;
  /** Hard deadline per render; Chrome/FFmpeg are aborted when it passes. Default 15 min. */
  renderTimeoutMs?: number;
  quality?: 'draft' | 'standard' | 'high';
}

const failed = (code: ProviderError['code'], message: string, raw?: unknown): ProviderResult<never> => {
  const error = new ProviderError(P, code, message, raw);
  return { status: 'failed', error, retryable: isRetryable(code) };
};

export class HyperframesRenderer implements RendererProvider {
  readonly id = P;
  constructor(private readonly o: HyperframesOptions) {}

  async render(req: RenderRequest): Promise<ProviderResult<MediaRef>> {
    const parsed = VideoSpec.safeParse(req.spec);
    if (!parsed.success) return failed('INVALID_INPUT', `Invalid VideoSpec: ${parsed.error.issues.map((i) => i.message).join('; ')}`);
    const spec = parsed.data;

    await mkdir(this.o.workDir, { recursive: true });
    const dir = await mkdtemp(join(this.o.workDir, 'project-'));
    const deadline = AbortSignal.timeout(this.o.renderTimeoutMs ?? 15 * 60_000);
    const started = Date.now();
    try {
      await stageProject(spec, this.o.storage, dir);
      await writeFile(join(dir, 'index.html'), composeHtml(spec));
      const out = join(dir, 'out.mp4');

      const job = createRenderJob({ fps: { num: spec.fps, den: 1 }, quality: this.o.quality ?? 'standard', format: 'mp4' });
      try {
        await executeRenderJob(job, dir, out, undefined, deadline);
      } catch (e) {
        if (deadline.aborted) return failed('TIMEOUT', `Render ${req.idempotencyKey} exceeded ${this.o.renderTimeoutMs ?? 900_000}ms`, e);
        return failed('UPSTREAM', `Render ${req.idempotencyKey} failed: ${(e as Error).message}`, e);
      }
      if (deadline.aborted) return failed('TIMEOUT', `Render ${req.idempotencyKey} exceeded its deadline`);
      if (job.status === 'failed' || job.status === 'cancelled') {
        return failed('UPSTREAM', `Render ${req.idempotencyKey} ${job.status} at ${job.failedStage ?? 'unknown stage'}: ${job.error ?? 'no error message'}`);
      }
      const info = await stat(out).catch(() => null);
      if (!info || info.size === 0) return failed('UPSTREAM', `Render ${req.idempotencyKey} produced no output file`);

      const ref = await this.o.storage.put(await readFile(out), {
        mime: 'video/mp4',
        width: spec.width,
        height: spec.height,
        durationSec: spec.durationInFrames / spec.fps,
      });
      return { status: 'done', value: ref, cost: { amountUsd: 0, estimated: false }, latencyMs: Date.now() - started };
    } catch (e) {
      if (e instanceof ProviderError) return { status: 'failed', error: e, retryable: isRetryable(e.code) };
      if (deadline.aborted) return failed('TIMEOUT', `Render ${req.idempotencyKey} exceeded its deadline`, e);
      // Staging errors (missing asset key) are input problems, not transient ones.
      if (/Render asset missing/.test((e as Error).message)) return failed('INVALID_INPUT', (e as Error).message, e);
      throw e;
    } finally {
      await drainBrowserPool().catch(() => {});
      await rm(dir, { recursive: true, force: true });
    }
  }
}

```markdown
# 0008 — HyperFrames renderer: composition per spec, offline, deadline-bounded

**Status:** accepted · 2026-10-16

## Decision
- **Pinned versions:** `@hyperframes/producer` and `@hyperframes/engine` **0.8.106** (2026-10-01), with every transitive `@hyperframes/*` package held at 0.8.106 via pnpm `overrides`. Upgrades are deliberate PRs.
- **One HTML composition per render,** generated from the `VideoSpec` by a pure function (`composeHtml`). HyperFrames composition variables are **not** used: the spec already holds every value, so there is no stringly-typed payload to validate.
- **Asset references are storage keys.** "assetId" in CLAUDE.md means `MediaRef.id`. `stageProject` copies each key into the project's `assets/`.
- **Offline render:** GSAP and fonts (Inter for Latin, Noto Sans Devanagari for Hindi) are copied from pinned npm packages into each project.
- **Timing:** frames are the source of truth. `secs()` floors to whole microseconds, so `ceil(duration × 30)` reproduces the frame count and frame *n* always falls inside its clip window. A test simulates every frame.
- **Composition rules:**
  - The plate and the cutout share one motion stage, so the real product never drifts against its scene.
  - B-roll `<video>` elements and `<audio>` sit at the root, as the HyperFrames lint rules require.
  - Each b-roll clip is trimmed to its scene by `data-duration` / `data-media-start`.
- **Liveness:**
  - each render has a deadline (`renderTimeoutMs`, default 15 min) through `executeRenderJob`'s abort signal; a timeout is a retryable `TIMEOUT`;
  - the browser pool is drained and the temp project removed after every render.
- **Idempotency** is the caller's job: P7's Inngest step memoization. The renderer itself does no caching.

## Measured
`pnpm e2e:render` (1080×1920, 600 frames, `standard` quality): [FILL IN from the e2e report] s on the i9-14900K, in Windows screenshot capture mode.

## Consequences
- Rendering is CPU- and RAM-heavy (Chrome plus FFmpeg). It belongs in P7's `heavy` lane alongside ComfyUI and TTS.
- Treatment parameters (caption position and weight, scrim) reach the renderer already resolved in the `VideoSpec`. Mapping a `visual_treatment` to them is P6's `buildSpec`'s job.
```
