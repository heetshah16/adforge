# P7: Pipeline — Inngest end to end, in a worker process — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** upload a product (3–5 photos plus name, price, description, language and a b-roll toggle) and get **three rendered MP4s** with no manual steps. Steps are durable and memoized, retries never re-render, partial success counts as success, and every heavy GPU/CPU task runs one at a time in a shared lane.

**Architecture:**
- **`apps/worker`** is a plain Node HTTP server, run with `tsx`, and is the **only process** that owns PGlite, storage and the pipeline. It serves:
  - `/api/inngest` (Inngest v4 `inngest/node`);
  - `POST /api/jobs`, `GET /api/jobs/:id` and `GET /media/<key>`;
  - `GET /health`.
  
  This replaces the roadmap's "`apps/web` hosts the API". Next.js would bundle our workspace packages, which read prompts, workflows, GSAP and fonts relative to `import.meta.url`, and PGlite allows only one process. So P8's Next UI proxies to the worker and never touches the DB. This matches architecture.md §2's separate `worker` service.
- **`packages/pipeline`** holds:
  - an orchestrator (`generateAds`), written against a small `StepLike` interface (`run`, `heavy`) so it is testable with a memoizing fake step;
  - heavy tasks (`plates`, `broll`, `voice`, `render`), each its own Inngest function sharing **one env-scoped concurrency key `"heavy"` (limit 1)** and called through `step.invoke`, which holds no slot while it waits;
  - a cron **janitor**;
  - `provider_calls` recording and the `configSnapshot`.

**Tech Stack:**
- `inngest` **4.21.1**; dev server `inngest-cli` **1.45.1** (pinned devDependency).
- Node 24 `node:http` + Web `Request` / `Response` / `FormData`. **No web framework.**
- Drizzle + PGlite, Zod 4, Vitest 5.

**Spec:** [spec](../specs/2026-10-15-adforge-local-poc-design.md) §4, §6, §7, §11. **Roadmap:** the P7 section plus the **liveness rule** and **heavy-lane / memory hand-off** bullets. **Inngest docs:** `inngest.com/docs/reference/typescript/functions/create`, `…/typescript/v4/migrations/v3-to-v4` and `…/guides/concurrency` (fetched 2026-10-16). They are summarized into `docs/providers/inngest.md` in Task 1.

## Global Constraints

- **No synchronous render path, not even in tests.** Tests drive `generateAds` through a fake `StepLike`, never by calling the renderer directly.
- **The heavy lane:** ComfyUI, b-roll, voice and render are four Inngest functions, all with `concurrency: [{ scope: 'env', key: '"heavy"', limit: 1 }]`.
- **Batching:** plates and cutout run as one batch, followed by ComfyUI `free()`. B-roll runs as one batch (if enabled), followed by `free()`. Voice and align run as one batch, followed by voice `unload()`. Then one render per variant. **Never interleave per beat.**
- **Partial success is first-class.** A variant failing (plate, voice or render) marks that variant `failed` and the job continues. A job with ≥1 completed variant is `completed` with `warnings`; zero completed means `failed`.
- **B-roll** only on an `absent` beat, only if `inputSpec.broll` is true, and **video is one retry unit**: a failed poll is followed by one re-`submit` with the same key. A b-roll failure degrades that beat to its plate and is never fatal.
- **Idempotency keys** are `jobId:<stage>:<variantNo>:<beat>`. `provider_calls` rows use `onConflictDoNothing`, so a duplicate key means "already recorded".
- **`step.run` results are JSON.** `ProviderError` is serialized explicitly (`{ code, message, retryable }`) before it leaves a step.
- **Liveness:**
  - functions have `timeouts`;
  - heavy batches have per-call deadlines (P2, P3 and P6 providers) plus a b-roll poll deadline;
  - the janitor (every 5 min) frees ComfyUI and unloads voice when no job is running, and fails jobs whose progress has been silent past `PIPELINE.jobs.staleAfterMin`;
  - the worker closes the DB (releasing the PGlite lock) on SIGINT/SIGTERM.
- **`configSnapshot`** (ADR 0006) records the pipeline config, treatments, provider ids, models and effort, workflow hashes and prompt hashes. **Never secrets.**
- **Exact pins, ≥2 weeks old.** `pnpm test` (typecheck first) before every commit: no GPU, no services, no network. **One end-to-end check** at the end (`pnpm e2e:pipeline <slug>`).
- Commits: `git -c user.name=heetshah16 -c user.email=shahheet85@gmail.com commit ...` with a `Co-Authored-By:` trailer naming the authoring model.

## Review Focus

1. **A step retried after its provider already succeeded** must not call the provider again (memoization). → Task 3 test, which re-runs with the same step cache.
2. **One variant's render fails** → the job ends `completed` with a warning naming the variant; **all fail** → the job ends `failed`. → Task 3 tests.
3. **The voice service is up without sm_120,** or ComfyUI is down. Preflight must fail the job fast, before any GPU work. → Task 3 test.
4. **Upload abuse:** 6 photos, a 10 MB photo, a `.exe` renamed `.png`, a missing name, a traversal key on `/media`. Each gets a clear 4xx, with nothing stored. → Task 4 tests.
5. **A worker killed mid-job** leaves the job `running` forever. The janitor must mark it `failed: stalled`. → Task 3 janitor test.

# Inngest — provider reference

**Fetched:** 2026-10-16 (inngest.com/docs: functions/create, v3→v4 migration, guides/concurrency). **Pinned:** `inngest` 4.21.1, `inngest-cli` 1.45.1 (dev server).

- **Client:** `new Inngest({ id: 'adforge', isDev: true })`. In v4, `baseUrl` / `fetch` / signing keys live on the client, not on `serve`.
- **Function:** `inngest.createFunction({ id, triggers: [{ event: 'x' } | { cron: '*/5 * * * *' }], concurrency, retries, timeouts }, async ({ event, step, runId, attempt, logger }) => …)`. Triggers moved into the options object in v4. A function with no triggers (invoke-only) omits `triggers`.
- **Concurrency** counts **executing steps**, not runs. `key` is a CEL expression, so `'"heavy"'` is a constant. With `scope: 'env'`, **different functions sharing the same key share one limit**. Configure every sharing function with the same scope, key and limit. `step.sleep` / `step.invoke` / `step.waitForEvent` hold no slot while waiting. A function may have at most 2 concurrency constraints.
- **Steps:**
  - `step.run(id, fn)` is a memoized, retriable unit; its result is serialized to JSON.
  - `step.invoke(id, { function, data })` calls another function by instance (v4 rejects a raw string).
  - `step.sleep(id, duration)` pauses.
- **Retries:** `retries` is 0–20 (default 4). Throwing inside `step.run` retries that step.
- **Timeouts:** `timeouts.start` (scheduled → started) and the execution timeout. **Verify the exact execution key name in the installed types** (`FunctionOptions['timeouts']`, likely `finish`).
- **Serving over node:http:** `import { serve } from 'inngest/node'`. Verify the export's call shape in the installed `inngest/node` types.
- **Dev server:** `inngest-cli dev -u http://127.0.0.1:3001/api/inngest`; its UI runs at http://127.0.0.1:8288.

import type { ProviderErrorCode, ProviderResult } from '@adforge/core/providers/types';

/** step.run results are JSON — ProviderError (non-enumerable message) must be flattened explicitly. */
export type WireResult<T> = { ok: true; value: T } | { ok: false; code: ProviderErrorCode; message: string; retryable: boolean };

export function toWire<T>(r: ProviderResult<T>): WireResult<T> {
  if (r.status === 'done') return { ok: true, value: r.value };
  if (r.status === 'failed') return { ok: false, code: r.error.code, message: r.error.message, retryable: r.retryable };
  return { ok: false, code: 'TIMEOUT', message: `still pending (${r.handle.externalId})`, retryable: true };
}

`packages/pipeline/src/record.ts`:
```ts
import { createHash } from 'node:crypto';
import { and, eq } from 'drizzle-orm';
import type { MediaRef, ProviderResult, StorageProvider } from '@adforge/core/providers/types';
import type { Db } from '@adforge/db/client';
import { assets, providerCalls } from '@adforge/db/schema';
import { toWire, type WireResult } from './wire';

const isWire = (r: unknown): r is WireResult<unknown> => typeof r === 'object' && r !== null && 'ok' in r;

/** A duplicate idempotency key means "already recorded" — never an error (retries re-enter here). */
export async function recordCall(
  db: Db,
  row: {
    jobId: string; variantId?: string; kind: string; provider: string; model?: string; idempotencyKey: string;
    result: WireResult<unknown> | ProviderResult<unknown>; latencyMs?: number; costUsd?: number;
  },
): Promise<void> {
  const w = isWire(row.result) ? row.result : toWire(row.result);
  await db
    .insert(providerCalls)
    .values({
      jobId: row.jobId,
      variantId: row.variantId,
      kind: row.kind,
      provider: row.provider,
      model: row.model,
      requestHash: createHash('sha256').update(row.idempotencyKey).digest('hex'),
      idempotencyKey: row.idempotencyKey,
      latencyMs: row.latencyMs,
      costUsd: row.costUsd ?? 0,
      status: w.ok ? 'done' : 'failed',
      error: w.ok ? null : { code: w.code, message: w.message, retryable: w.retryable },
    })
    .onConflictDoNothing({ target: providerCalls.idempotencyKey });
}

export async function saveAsset(db: Db, projectId: string, kind: string, ref: MediaRef): Promise<string> {
  await db
    .insert(assets)
    .values({ projectId, kind, storageKey: ref.id, mime: ref.mime, width: ref.width, height: ref.height, durationSec: ref.durationSec, bytes: ref.bytes, sha256: ref.sha256 })
    .onConflictDoNothing();
  const [row] = await db.select({ id: assets.id }).from(assets).where(and(eq(assets.projectId, projectId), eq(assets.sha256, ref.sha256)));
  return row!.id;
}

const MIME: Record<string, string> = { png: 'image/png', jpg: 'image/jpeg', webp: 'image/webp', mp4: 'video/mp4', wav: 'audio/wav' };
export async function refFromKey(storage: StorageProvider & { pathFor?(k: string): string }, key: string): Promise<MediaRef> {
  const bytes = await storage.read(key);
  const ext = key.split('.').pop()!;
  return { id: key, url: key, mime: MIME[ext] ?? 'application/octet-stream', sha256: key.slice(3, 67), bytes: bytes.byteLength };
}

It generates every beat's plate (`${scene.scene}, ${treatment.platePromptSuffix}`, size `PIPELINE.plate`, key `jobId:plate:<v>:<b>`), then the cutout of `photoKey` (key `jobId:cutout`). It **always** calls `comfy.free()` in `finally`.
  - `broll(deps, p: { jobId; variants; plates }): Promise<BrollResult>`. For each variant, it takes the first `absent` beat with a plate, submits `image_to_video` (`durationSec: PIPELINE.broll.durationSec`, key `jobId:broll:<v>`) and polls until done or `PIPELINE.broll.pollDeadlineMs`, sleeping `handle.pollAfterMs` through `deps.sleep`. On a retryable failure it re-submits **once** with the same key. Failures are `null`. It always calls `comfy.free()`.
  - `voice(deps, p: { jobId; language; variants }): Promise<VoiceResult>`. Before the first beat it verifies the ComfyUI `free()` hand-off took effect: it polls `comfy.systemStats()` (via `deps.sleep`, up to 20 s) until VRAM in use is under half of total, then goes ahead regardless. Per beat it synthesizes `ttsText(scene, language)` (key `jobId:tts:<v>:<b>`; Devanagari `vo_tts` for Hinglish), then aligns that same text (key `jobId:align:<v>:<b>`). Captions come from `alignCaptions(scene, language, asrWords, dur)`; if alignment fails, ASR words are `[]` and captions fall back to the proportional slots; a TTS failure gives `null`. It **always** calls `voice.unload()`.
  - `render(deps, p: { jobId; variantNo; spec: VideoSpec }): Promise<RenderResult>`. It renders (key `jobId:render:<v>`) and saves the asset (kind `render`).
  - **Every provider call** is recorded with `recordCall`, and every produced `MediaRef` saved with `saveAsset` (kinds `plate`, `cutout`, `broll`, `voice`, `render`).
- Produces (`test/fakes.ts`): `makeDeps(over?)`. It builds `PipelineDeps` with in-memory PGlite (migrated, seeded, local user), tmp `LocalDiskStorage`, and fake comfy/voice/renderer/LLM whose call counts are exposed as `deps.calls`. Each fake can be told to fail.

import { PIPELINE } from '@adforge/core/config/pipeline';
import { TREATMENTS } from '@adforge/core/config/treatments';
import type { DirectorVariant } from '@adforge/core/llm/schemas';
import type { MediaRef, ProviderResult } from '@adforge/core/providers/types';
import { ttsText } from '@adforge/core/llm/tts-text';
import { alignCaptions } from '@adforge/core/spec/align-captions';
import type { VideoSpec } from '@adforge/core/spec/video-spec';
import type { Language } from '@adforge/core/vocab/enums';
import { recordCall, refFromKey, saveAsset } from './record';
import type { BrollResult, PipelineDeps, PlateResult, RenderResult, VoiceResult } from './types';
import { toWire } from './wire';

async function call<T>(deps: PipelineDeps, jobId: string, kind: string, provider: string, idempotencyKey: string, run: () => Promise<ProviderResult<T>>) {
  const r = await run();
  await recordCall(deps.db, {
    jobId, kind, provider, idempotencyKey, result: r,
    latencyMs: r.status === 'done' ? r.latencyMs : undefined, costUsd: r.status === 'done' ? r.cost.amountUsd : 0,
  });
  return r;
}
const keep = async (deps: PipelineDeps, kind: string, r: ProviderResult<MediaRef>) =>
  r.status === 'done' ? (await saveAsset(deps.db, deps.projectId, kind, r.value), r.value) : null;

export const HEAVY = {
  async plates(deps: PipelineDeps, p: { jobId: string; variants: DirectorVariant[]; photoKey: string }): Promise<PlateResult> {
    const plates: Record<string, string | null> = {};
    try {
      for (const v of p.variants) {
        for (const [b, s] of v.scenes.entries()) {
          const key = `${p.jobId}:plate:${v.variant_no}:${b}`;
          const r = await call(deps, p.jobId, 'image', deps.comfy.image.id, key, () =>
            deps.comfy.image.generate({ prompt: `${s.scene}, ${TREATMENTS[v.visual_treatment].platePromptSuffix}`, width: PIPELINE.plate.width, height: PIPELINE.plate.height, idempotencyKey: key }),
          );
          plates[`${v.variant_no}:${b}`] = (await keep(deps, 'plate', r))?.id ?? null;
        }
      }
      const photo = await refFromKey(deps.storage, p.photoKey);
      const c = await call(deps, p.jobId, 'cutout', deps.comfy.cutout.id, `${p.jobId}:cutout`, () =>
        deps.comfy.cutout.cutout({ image: photo, idempotencyKey: `${p.jobId}:cutout` }),
      );
      return { cutout: (await keep(deps, 'cutout', c))?.id ?? null, plates };
    } finally {
      await deps.comfy.free().catch(() => {});
    }
  },

  async broll(deps: PipelineDeps, p: { jobId: string; variants: DirectorVariant[]; plates: Record<string, string | null> }): Promise<BrollResult> {
    const out: BrollResult = {};
    try {
      for (const v of p.variants) {
        const beat = v.scenes.findIndex((s, b) => s.product_prominence === 'absent' && p.plates[`${v.variant_no}:${b}`]);
        if (beat < 0) { out[v.variant_no] = null; continue; }
        const key = `${p.jobId}:broll:${v.variant_no}`;
        const firstFrame = await refFromKey(deps.storage, p.plates[`${v.variant_no}:${beat}`]!);
        let result: ProviderResult<MediaRef> | null = null;
        for (let attempt = 0; attempt < 2; attempt++) {
          const handle = await deps.comfy.video.submit({
            mode: 'image_to_video', prompt: `${v.scenes[beat]!.scene}, subtle ambient motion, static camera`, firstFrame,
            durationSec: PIPELINE.broll.durationSec, aspectRatio: '9:16', resolution: '720p', idempotencyKey: key,
          });
          const deadline = Date.now() + PIPELINE.broll.pollDeadlineMs;
          let r = await deps.comfy.video.poll(handle);
          while (r.status === 'pending' && Date.now() < deadline) {
            await deps.sleep(handle.pollAfterMs);
            r = await deps.comfy.video.poll(handle);
          }
          result = r;
          if (r.status === 'done' || (r.status === 'failed' && !r.retryable)) break;
        }
        await recordCall(deps.db, { jobId: p.jobId, kind: 'video', provider: deps.comfy.video.id, idempotencyKey: key, result: result! });
        const ref = result ? await keep(deps, 'broll', result) : null;
        out[v.variant_no] = ref ? { beat, key: ref.id, durationSec: ref.durationSec ?? PIPELINE.broll.durationSec } : null;
      }
      return out;
    } finally {
      await deps.comfy.free().catch(() => {});
    }
  },

  async voice(deps: PipelineDeps, p: { jobId: string; language: Language; variants: DirectorVariant[] }): Promise<VoiceResult> {
    const out: VoiceResult = {};
    try {
      // The plates batch freed ComfyUI; confirm VRAM actually dropped before the voice model loads (best-effort, 20 s).
      for (let waited = 0; waited < 20_000; waited += 1000) {
        const st = await deps.comfy.systemStats().catch(() => null);
        if (!st || st.vramUsedBytes < st.vramTotalBytes / 2) break;
        await deps.sleep(1000);
      }
      for (const v of p.variants) {
        for (const [b, s] of v.scenes.entries()) {
          const text = ttsText(s, p.language);
          const tKey = `${p.jobId}:tts:${v.variant_no}:${b}`;
          const t = await call(deps, p.jobId, 'tts', deps.voice.tts.id, tKey, () =>
            deps.voice.tts.synthesize({ text, language: p.language, emotion: s.emotion, idempotencyKey: tKey }),
          );
          const audio = await keep(deps, 'voice', t);
          if (!audio) { out[`${v.variant_no}:${b}`] = null; continue; }
          const dur = audio.durationSec ?? 0;
          const aKey = `${p.jobId}:align:${v.variant_no}:${b}`;
          const a = await call(deps, p.jobId, 'align', deps.voice.aligner.id, aKey, () =>
            deps.voice.aligner.align({ audio, text, language: p.language, idempotencyKey: aKey }),
          );
          const words = alignCaptions(s, p.language, a.status === 'done' ? a.value.words : [], dur);
          out[`${v.variant_no}:${b}`] = { key: audio.id, durationSec: dur, words };
        }
      }
      return out;
    } finally {
      await deps.voice.unload().catch(() => {});
    }
  },

  async render(deps: PipelineDeps, p: { jobId: string; variantNo: number; spec: VideoSpec }): Promise<RenderResult> {
    const key = `${p.jobId}:render:${p.variantNo}`;
    const r = await call(deps, p.jobId, 'render', deps.renderer.id, key, () => deps.renderer.render({ spec: p.spec, idempotencyKey: key }));
    const w = toWire(r);
    if (!w.ok) return { error: w.message };
    return { key: w.value.id, assetId: await saveAsset(deps.db, deps.projectId, 'render', w.value) };
  },
} as const;

`packages/pipeline/src/orchestrate.ts`:
```ts
import { and, eq } from 'drizzle-orm';
import { direct } from '@adforge/core/llm/direct';
import { strategize } from '@adforge/core/llm/strategize';
import type { DirectorVariant, StrategistOutput } from '@adforge/core/llm/schemas';
import { buildSpec } from '@adforge/core/spec/build-spec';
import type { VideoSpec } from '@adforge/core/spec/video-spec';
import { shortlist, type Shortlist } from '@adforge/core/vocab/shortlist';
import { loadRegistry } from '@adforge/db/registry';
import { jobs, providerCalls, variants } from '@adforge/db/schema';
import { markProgress, setJobStatus } from './progress';
import { recordCall } from './record';
import { buildConfigSnapshot } from './snapshot';
import type { JobInput, PipelineDeps, StepLike } from './types';
import { toWire } from './wire';

class Retry extends Error {}
type Out = { status: 'completed' | 'failed'; warnings: string[] };

export async function generateAds(jobId: string, step: StepLike, deps: PipelineDeps): Promise<Out> {
  const { db } = deps;
  const fail = async (stage: string, reason: unknown): Promise<Out> => {
    await step.run(`fail:${stage}`, async () => {
      await markProgress(db, jobId, stage, 'failed', String((reason as { message?: string })?.message ?? JSON.stringify(reason)));
      await setJobStatus(db, jobId, { status: 'failed', error: { stage, reason }, completedAt: new Date() });
      return true;
    });
    return { status: 'failed', warnings: [] };
  };

  const input = await step.run('load', async () => {
    const [j] = await db.select().from(jobs).where(eq(jobs.id, jobId));
    if (!j) throw new Error(`job ${jobId} not found`);
    await setJobStatus(db, jobId, { status: 'running' });
    return j.inputSpec as JobInput;
  });

  const pre = await step.run('preflight', async () => {
    await markProgress(db, jobId, 'preflight', 'running');
    try {
      await deps.comfy.preflight();
      const h = await deps.voice.health();
      if (!h.ok || !h.sm120) return { error: `voice service unhealthy (ok=${h.ok}, sm120=${h.sm120})` };
    } catch (e) {
      return { error: (e as Error).message };
    }
    await setJobStatus(db, jobId, { configSnapshot: buildConfigSnapshot({ env: deps.env, workflowHashes: deps.comfy.workflowHashes }) });
    await markProgress(db, jobId, 'preflight', 'done');
    return { ok: true as const };
  });
  if ('error' in pre) return fail('preflight', pre.error);

  // --- LLM stages (not in the heavy lane) ----------------------------------------------------
  const brief = await step.run('strategize', async () => {
    await markProgress(db, jobId, 'strategize', 'running');
    const registry = await loadRegistry(db);
    const images = await Promise.all(
      input.photoKeys.map(async (k) => ({ mime: (k.endsWith('.png') ? 'image/png' : k.endsWith('.webp') ? 'image/webp' : 'image/jpeg') as 'image/png', data: await deps.storage.read(k) })),
    );
    const r = await strategize({ product: input.product, images }, registry, {
      llm: deps.llm, model: deps.env.ADFORGE_LLM_STRATEGIST, effort: deps.env.ADFORGE_LLM_EFFORT_STRATEGIST, idempotencyKey: `${jobId}:strategize`,
    });
    const w = toWire(r);
    await recordCall(db, { jobId, kind: 'llm', provider: deps.llm.id, model: deps.env.ADFORGE_LLM_STRATEGIST, idempotencyKey: `${jobId}:strategize`, result: w, latencyMs: r.status === 'done' ? r.latencyMs : undefined, costUsd: r.status === 'done' ? r.cost.amountUsd : 0 });
    if (!w.ok && w.retryable) throw new Retry(w.message);
    if (w.ok) { await setJobStatus(db, jobId, { brief: w.value.value }); await markProgress(db, jobId, 'strategize', 'done'); }
    return w.ok ? { brief: w.value.value } : { error: w };
  });
  if ('error' in brief) return fail('strategize', brief.error);

  const list = await step.run('shortlist', async () => {
    const registry = await loadRegistry(db);
    const s = shortlist({ archetypePrimary: brief.brief.archetype_primary, archetypeSecondary: brief.brief.archetype_secondary }, registry);
    await setJobStatus(db, jobId, { shortlist: s });
    return s;
  });

  const direction = await step.run('direct', async () => {
    await markProgress(db, jobId, 'direct', 'running');
    const registry = await loadRegistry(db);
    const d = await direct({ product: input.product, brief: brief.brief as StrategistOutput, shortlist: list as Shortlist, registry, language: input.language }, {
      llm: deps.llm, model: deps.env.ADFORGE_LLM_DIRECTOR, effort: deps.env.ADFORGE_LLM_EFFORT_DIRECTOR, idempotencyKey: `${jobId}:direct`,
    });
    // One provider_calls row per Director call (first + repair), with real cost and latency (P5 final review I2).
    for (const c of d.calls) {
      await recordCall(db, {
        jobId, kind: 'llm', provider: deps.llm.id, model: deps.env.ADFORGE_LLM_DIRECTOR, idempotencyKey: c.idempotencyKey,
        result: toWire(c.result),
        latencyMs: c.result.status === 'done' ? c.result.latencyMs : undefined,
        costUsd: c.result.status === 'done' ? c.result.cost.amountUsd : 0,
      });
    }
    if (d.status === 'failed') {
      if (d.retryable) throw new Retry(d.error.message);
      return { error: { code: d.error.code, message: d.error.message } };
    }
    if (d.status === 'violations') return { error: { violations: d.violations } };
    const exp = (list as Shortlist).experimental;
    for (const v of d.output.variants) {
      await db.insert(variants).values({
        jobId, variantNo: v.variant_no, formatSlug: v.format, hookSlug: v.hook_archetype, archetypeSlug: brief.brief.archetype_primary,
        visualTreatment: v.visual_treatment, strategicBet: v.strategic_bet,
        isExploratory: !!exp && v.variant_no === 3, direction: v, status: 'running',
      }).onConflictDoNothing();
    }
    await markProgress(db, jobId, 'direct', 'done', `repairs=${d.repairs}`);
    return { variants: d.output.variants };
  });
  if ('error' in direction) return fail('direct', direction.error);
  const vs = direction.variants as DirectorVariant[];
  const warnings: string[] = [];
  const oneVariant = (n: number) => and(eq(variants.jobId, jobId), eq(variants.variantNo, n));
  const failVariant = async (n: number, why: string) => {
    warnings.push(`variant ${n}: ${why}`);
    await step.run(`variant-failed:${n}`, async () => {
      await db.update(variants).set({ status: 'failed', error: { why } }).where(oneVariant(n));
      return true;
    });
  };

  // --- heavy lane, batched by model -----------------------------------------------------------
  await step.run('mark:plates', () => markProgress(db, jobId, 'plates', 'running').then(() => true));
  const plates = await step.heavy('plates', 'heavy:plates', { jobId, variants: vs, photoKey: input.photoKeys[0]! });
  await step.run('mark:plates:done', () => markProgress(db, jobId, 'plates', 'done').then(() => true));

  let broll: Record<string, { beat: number; key: string; durationSec: number } | null> = {};
  if (input.broll) {
    broll = await step.heavy('broll', 'heavy:broll', { jobId, variants: vs, plates: plates.plates });
    for (const v of vs) if (!broll[v.variant_no]) warnings.push(`variant ${v.variant_no}: b-roll unavailable, using plate`);
  } else {
    await step.run('mark:broll:skipped', () => markProgress(db, jobId, 'broll', 'skipped').then(() => true));
  }

  const voice = await step.heavy('voice', 'heavy:voice', { jobId, language: input.language, variants: vs });
  await step.run('mark:voice:done', () => markProgress(db, jobId, 'voice', 'done').then(() => true));

  let completed = 0;
  for (const v of vs) {
    const n = v.variant_no;
    const beats = v.scenes.map((_, b) => ({ plate: plates.plates[`${n}:${b}`], voice: voice[`${n}:${b}`] }));
    if (!plates.cutout || beats.some((x) => !x.plate || !x.voice)) {
      await failVariant(n, 'missing plate, cutout or voice');
      continue;
    }
    const spec = await step.run(`spec:${n}`, async () =>
      buildSpec({
        id: `${jobId}-v${n}`,
        variant: v,
        beats: beats.map((x, b) => ({
          plate: x.plate!, cutout: plates.cutout!, voice: { key: x.voice!.key, durationSec: x.voice!.durationSec }, words: x.voice!.words,
          ...(broll[n]?.beat === b ? { broll: { key: broll[n]!.key, durationSec: broll[n]!.durationSec } } : {}),
        })),
      }),
    );
    await step.run(`mark:render:${n}`, () => markProgress(db, jobId, 'render', 'running', `variant ${n}`).then(() => true));
    const out = await step.heavy('render', `heavy:render:${n}`, { jobId, variantNo: n, spec: spec as VideoSpec });
    if ('error' in out) { await failVariant(n, `render failed: ${out.error}`); continue; }
    await step.run(`variant-done:${n}`, async () => {
      await db.update(variants).set({ status: 'completed', renderAssetId: out.assetId }).where(oneVariant(n));
      return true;
    });
    completed++;
  }

  return step.run('finalize', async () => {
    const calls = await db.select({ c: providerCalls.costUsd }).from(providerCalls).where(eq(providerCalls.jobId, jobId));
    const cost = calls.reduce((s, x) => s + (x.c ?? 0), 0);
    const status = completed > 0 ? 'completed' : 'failed';
    await setJobStatus(db, jobId, { status, costUsd: cost, completedAt: new Date(), error: warnings.length ? { warnings } : null });
    await markProgress(db, jobId, 'finalize', status === 'completed' ? 'done' : 'failed', `${completed}/3 variants`);
    return { status, warnings } as Out;
  });
}
```

Variant updates are always scoped to one variant (`oneVariant(n)`). The `render` stage logs one `running` entry per variant; `finalize` closes it.

```ts
import { eq } from 'drizzle-orm';
import { PIPELINE } from '@adforge/core/config/pipeline';
import { jobs } from '@adforge/db/schema';
import type { PipelineDeps } from './types';

/** Liveness sweep (every 5 min): fail silent jobs, then free ComfyUI + voice if no job is running. */
export async function runJanitor(deps: PipelineDeps): Promise<{ freed: boolean; stalled: string[] }> {
  const cutoff = Date.now() - PIPELINE.jobs.staleAfterMin * 60_000;
  const running = await deps.db.select().from(jobs).where(eq(jobs.status, 'running'));
  const stalled: string[] = [];
  for (const j of running) {
    const last = j.progress.at(-1)?.at ?? j.createdAt.toISOString();
    if (Date.parse(last) < cutoff) {
      await deps.db.update(jobs).set({ status: 'failed', completedAt: new Date(), error: { stage: 'janitor', reason: `stalled: no progress since ${last}` } }).where(eq(jobs.id, j.id));
      stalled.push(j.id);
    }
  }
  const stillRunning = running.length - stalled.length;
  if (stillRunning > 0) return { freed: false, stalled };
  await deps.comfy.free().catch(() => {});
  await deps.voice.unload().catch(() => {});
  return { freed: true, stalled };
}

import { Inngest } from 'inngest';
import { HEAVY } from './heavy';
import { generateAds } from './orchestrate';
import { runJanitor } from './janitor';
import type { PipelineDeps, StepLike } from './types';

export const inngest = new Inngest({ id: 'adforge', isDev: true });
export const EVENTS = { jobRequested: 'adforge/job.requested' } as const;

/** One GPU/CPU-heavy step at a time across ALL heavy functions (env scope + constant key = shared lane). */
export const HEAVY_CONCURRENCY = [{ scope: 'env' as const, key: '"heavy"', limit: 1 }];

export function createFunctions(deps: PipelineDeps) {
  const heavyFn = <K extends keyof typeof HEAVY>(task: K, finish: string) =>
    inngest.createFunction(
      { id: `heavy-${task}`, concurrency: HEAVY_CONCURRENCY, retries: 2, timeouts: { start: '2h', finish } },
      async ({ event, step }) => step.run(task, () => (HEAVY[task] as (d: PipelineDeps, p: unknown) => Promise<unknown>)(deps, event.data)),
    );
  const heavy = { plates: heavyFn('plates', '30m'), broll: heavyFn('broll', '60m'), voice: heavyFn('voice', '30m'), render: heavyFn('render', '30m') };

  const generate = inngest.createFunction(
    { id: 'generate-ads', triggers: [{ event: EVENTS.jobRequested }], retries: 2, concurrency: [{ limit: 2 }], timeouts: { finish: '4h' } },
    async ({ event, step }) => {
      const s: StepLike = {
        run: (id, fn) => step.run(id, fn) as never,
        heavy: (task, id, payload) => step.invoke(id, { function: heavy[task], data: payload as never }) as never,
      };
      return generateAds((event.data as { jobId: string }).jobId, s, deps);
    },
  );

  const janitor = inngest.createFunction({ id: 'janitor', triggers: [{ cron: '*/5 * * * *' }], retries: 0 }, async ({ step }) =>
    step.run('sweep', () => runJanitor(deps)),
  );
  return [generate, heavy.plates, heavy.broll, heavy.voice, heavy.render, janitor];
}

import type { IncomingMessage, ServerResponse } from 'node:http';
import { Readable } from 'node:stream';

/** node:http → Web Request (so every route is a plain (Request) => Response function). */
export function toRequest(req: IncomingMessage, base: string): Request {
  const headers = new Headers();
  for (const [k, v] of Object.entries(req.headers)) {
    if (Array.isArray(v)) for (const x of v) headers.append(k, x);
    else if (v !== undefined) headers.set(k, v);
  }
  const method = req.method ?? 'GET';
  const body = method === 'GET' || method === 'HEAD' ? undefined : (Readable.toWeb(req) as ReadableStream<Uint8Array>);
  return new Request(new URL(req.url ?? '/', base), { method, headers, body, duplex: 'half' } as RequestInit);
}

export async function send(res: ServerResponse, r: Response): Promise<void> {
  res.writeHead(r.status, Object.fromEntries(r.headers));
  if (r.body) for await (const chunk of r.body as unknown as AsyncIterable<Uint8Array>) res.write(chunk);
  res.end();
}

import { eq } from 'drizzle-orm';
import { z } from 'zod';
import { Language } from '@adforge/core/vocab/enums';
import { assets, jobs, variants } from '@adforge/db/schema';
import type { PipelineDeps } from '@adforge/pipeline';

const MAX_BODY = 30 * 1024 * 1024;
const MAX_PHOTO = 5 * 1024 * 1024;
const TYPES = { 'image/png': [0x89, 0x50, 0x4e, 0x47], 'image/jpeg': [0xff, 0xd8, 0xff], 'image/webp': [0x52, 0x49, 0x46, 0x46] } as const;
const Fields = z.object({
  name: z.string().trim().min(1, 'name is required').max(120),
  price: z.string().trim().min(1, 'price is required').max(40),
  description: z.string().trim().min(1, 'description is required').max(2000),
  /** Optional; the brand the hook must not name. Falls back to a guarded first word of `name` (P5 direct.ts). */
  brand: z.string().trim().max(60).optional(),
  language: Language,
  broll: z.boolean(),
});
const json = (body: unknown, status = 200) => new Response(JSON.stringify(body), { status, headers: { 'content-type': 'application/json' } });
const bad = (error: string, issues?: unknown) => json({ error, issues }, 400);
const sniff = (b: Uint8Array, type: keyof typeof TYPES) => TYPES[type].every((x, i) => b[i] === x) && (type !== 'image/webp' || String.fromCharCode(...b.slice(8, 12)) === 'WEBP');

export function makeRoutes(ctx: { deps: PipelineDeps; storage: LocalDiskStorage; sendEvent(name: string, data: unknown): Promise<void> }) {
  const { deps, storage } = ctx;
  const mediaUrl = (key: string) => `${deps.env.ADFORGE_PUBLIC_URL}/media/${key}`;

  return {
    async health() {
      return json({ ok: true });
    },

    async createJob(req: Request): Promise<Response> {
      if (Number(req.headers.get('content-length') ?? 0) > MAX_BODY) return json({ error: 'upload larger than 30 MB' }, 413);
      let form: FormData;
      try { form = await req.formData(); } catch { return bad('expected multipart/form-data'); }
      const fields = Fields.safeParse({
        name: form.get('name') ?? '', price: form.get('price') ?? '', description: form.get('description') ?? '',
        brand: form.get('brand') || undefined,
        language: form.get('language'), broll: ['on', 'true'].includes(String(form.get('broll') ?? '')),
      });
      if (!fields.success) return bad('invalid fields', z.flattenError(fields.error).fieldErrors);
      const photos = form.getAll('photos').filter((p): p is File => p instanceof File);
      if (photos.length < 3 || photos.length > 5) return bad(`need 3–5 photos, got ${photos.length}`);
      const loaded: { bytes: Uint8Array; type: keyof typeof TYPES }[] = [];
      for (const p of photos) {
        if (!(p.type in TYPES)) return bad(`${p.name}: unsupported type ${p.type || 'unknown'} (png, jpeg, webp only)`);
        if (p.size > MAX_PHOTO) return bad(`${p.name}: larger than 5 MB`);
        const bytes = new Uint8Array(await p.arrayBuffer());
        if (!sniff(bytes, p.type as keyof typeof TYPES)) return bad(`${p.name}: not a real ${p.type} file`);
        loaded.push({ bytes, type: p.type as keyof typeof TYPES });
      }
      const photoKeys: string[] = [];
      for (const { bytes, type } of loaded) {
        const ref = await storage.put(bytes, { mime: type });
        await saveAsset(deps.db, deps.projectId, 'upload', ref);
        photoKeys.push(ref.id);
      }
      const f = fields.data;
      const [job] = await deps.db.insert(jobs).values({
        projectId: deps.projectId, userId: deps.userId,
        inputSpec: { product: { name: f.name, price: f.price, description: f.description, ...(f.brand ? { brand: f.brand } : {}) }, language: f.language, broll: f.broll, photoKeys },
      }).returning();
      await ctx.sendEvent('adforge/job.requested', { jobId: job!.id });
      return json({ jobId: job!.id }, 202);
    },

    async getJob(req: Request): Promise<Response> {
      const id = new URL(req.url).pathname.split('/').pop() ?? '';
      if (!z.uuid().safeParse(id).success) return json({ error: 'not found' }, 404);
      const [j] = await deps.db.select().from(jobs).where(eq(jobs.id, id));
      if (!j) return json({ error: 'not found' }, 404);
      const vs = await deps.db.select().from(variants).leftJoin(assets, eq(variants.renderAssetId, assets.id)).where(eq(variants.jobId, id));
      return json({
        job: { id: j.id, status: j.status, progress: j.progress, brief: j.brief, error: j.error, costUsd: j.costUsd, createdAt: j.createdAt, completedAt: j.completedAt },
        variants: vs
          .map(({ variants: v, assets: a }) => ({
            variantNo: v.variantNo, formatSlug: v.formatSlug, hookSlug: v.hookSlug, visualTreatment: v.visualTreatment,
            strategicBet: v.strategicBet, isExploratory: v.isExploratory, status: v.status, renderUrl: a ? mediaUrl(a.storageKey) : null,
          }))
          .sort((a, b) => a.variantNo - b.variantNo),
      });
    },

    async getMedia(req: Request): Promise<Response> {
      const key = decodeURIComponent(new URL(req.url).pathname.replace(/^\/media\//, ''));
      let path: string;
      try { path = storage.pathFor(key); } catch { return json({ error: 'invalid media key' }, 400); }
      const bytes = await storage.read(key).catch(() => null);
      if (!bytes) return json({ error: 'not found' }, 404);
      const ext = path.split('.').pop()!;
      const type = { png: 'image/png', jpg: 'image/jpeg', webp: 'image/webp', mp4: 'video/mp4', wav: 'audio/wav' }[ext] ?? 'application/octet-stream';
      // ponytail: no Range support — fine for start-to-end playback in the review UI; add byte ranges if scrubbing is needed.
      return new Response(bytes, { headers: { 'content-type': type, 'content-length': String(bytes.byteLength), 'cache-control': 'public, max-age=31536000, immutable' } });
    },
  };
}

const server = createServer(async (req, res) => {
  try {
    const url = new URL(req.url ?? '/', base);
    if (url.pathname.startsWith('/api/inngest')) return void inngestHandler(req, res);
    const r = toRequest(req, base);
    const handler =
      req.method === 'POST' && url.pathname === '/api/jobs' ? routes.createJob
      : req.method === 'GET' && /^\/api\/jobs\/[^/]+$/.test(url.pathname) ? routes.getJob
      : req.method === 'GET' && url.pathname.startsWith('/media/') ? routes.getMedia
      : req.method === 'GET' && url.pathname === '/health' ? routes.health
      : null;
    await send(res, handler ? await handler(r) : new Response('not found', { status: 404 }));
  } catch (e) {
    console.error(e);
    if (!res.headersSent) res.writeHead(500).end('internal error');
  }
});
server.requestTimeout = 120_000; // liveness: no request may hang the worker
server.listen(env.ADFORGE_WORKER_PORT, '127.0.0.1', () => console.log(`worker on ${base}`));

  stopping = true;
  console.log(`${signal}: closing`);
  server.close();
  await close(); // releases the PGlite lock
  process.exit(0);
};

# 0011 — Worker process owns the pipeline; one shared heavy lane

**Status:** accepted · 2026-10-16

## Decision
- **The worker owns the pipeline.** `apps/worker` is a plain Node `node:http` server, run by `tsx`, and is the **only** process that opens PGlite and storage and runs Inngest functions. P8's Next.js UI proxies `/api/*` and `/media/*` to it and never imports server packages.
  - **Why:** Next would bundle our workspace packages, which read prompts, workflows, GSAP and fonts relative to `import.meta.url`. PGlite is single-process.
- **The heavy lane:** `heavy-plates`, `heavy-broll`, `heavy-voice` and `heavy-render` are separate Inngest functions, all with `concurrency: [{ scope: 'env', key: '"heavy"', limit: 1 }]`, called with `step.invoke`, which holds no slot while waiting. The LLM stages run outside the lane.
- **Batches by model, with hand-off:**
  1. plates and cutout, then ComfyUI `/free`;
  2. b-roll, then `/free`;
  3. voice and align, then voice `/unload`;
  4. one render per variant.
- **Partial success:** the job is `completed` when ≥1 variant finishes; failed variants carry their reason.
- **Liveness:** function timeouts, the request timeout on the worker, a 5-minute janitor (fails jobs silent for 60 min, frees GPU holders when idle), and graceful shutdown that releases the PGlite lock.
