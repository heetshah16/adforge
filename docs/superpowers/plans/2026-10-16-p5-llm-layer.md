# P5: LLM Layer — Strategist + Director via Claude Agent SDK — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- **`strategize()`** classifies a product by buying psychology, from photos plus seller text.
- **`direct()`** writes three variants **chosen only from the shortlist**. They must be diverse at family level, obey the hook, timing, copy and language rules in code, and get exactly one repair pass that names each violation.

Both run on Claude through the **Claude Agent SDK** under the user's subscription, behind an `LLMProvider` seam.

**Architecture:**
- **`packages/core`** holds everything model-agnostic:
  - the `LLMProvider` type;
  - schema **factories** that bake the live registry and shortlist slugs into the JSON schema, so constrained decoding can only emit valid slugs;
  - byte-frozen system prompts;
  - rule checks;
  - `strategize` / `direct` orchestration.
- **`packages/providers/claude-agent-sdk`** is the only code that imports the SDK. It runs one single-turn `query()` with tools disabled, user settings ignored, a temp `cwd`, `outputFormat` as JSON schema, and an abort deadline.

**Tech Stack:**
- `@anthropic-ai/claude-agent-sdk` **0.3.287** (2026-10-01), plus peers `@anthropic-ai/sdk` 0.131.0 and `@modelcontextprotocol/sdk` 1.31.0. All exact and at least 2 weeks old.
- Zod 4 (`z.toJSONSchema(schema, { target: 'draft-7' })`), Vitest 5.

**Spec:** [spec](../specs/2026-10-15-adforge-local-poc-design.md) §6, §11; [build spec](../../adforge-build-spec.md) §3–4, §6–7 (prompts, anchors, rules); architecture.md §8. **Roadmap:** P5 section plus the liveness rule. **Agent SDK docs:** `code.claude.com/docs/en/agent-sdk/structured-outputs`, `…/agent-sdk/typescript` (fetched 2026-10-16; summarized into `docs/providers/claude-agent-sdk.md` in Task 2).

## Global Constraints

- **Never set `temperature`, `top_p` or `top_k`.** Use `effort` (`low`→`max`) and prompting.
- **Structured output only.** Use `outputFormat: { type: 'json_schema', schema }`, then re-validate with Zod. Never string-concatenate model output into anything; serialize objects.
- **System prompts are byte-frozen `.md` files.** Never interpolate the product, job, date or shortlist into them; all of that goes in the **user** message. Their SHA-256 goes into `configSnapshot` (P7).
- **The vocabulary is data:**
  - archetype, format and hook menus are rendered from the `Registry` and the `Shortlist`;
  - the closed enums (`VisualTreatment`, `Motion`, `ProductProminence`, `Language`) come from `@adforge/core/vocab/enums`;
  - numeric rules come from `PIPELINE`.
- **Diversity is family-level** (P4 `assertVariantDiversity`), plus `offShortlist`, plus the rules in Task 4. It gets **one** repair pass, then fails with the violations.
- **Model ids come from env** (`ADFORGE_LLM_STRATEGIST` / `ADFORGE_LLM_DIRECTOR`) and are parsed at boot. A malformed id fails startup.
- **Liveness:**
  - every `generate` has a deadline (`PIPELINE.llm.timeoutMs`, default 300 s) through `abortController`; a timeout is a retryable `TIMEOUT`;
  - subscription rate or usage limits map to a retryable `RATE_LIMIT`, and auth failures to a non-retryable `AUTH`.
- **Subscription auth is for local POC use only** (ADR 0009). The SDK runs with `settingSources: []`, `persistSession: false` and `cwd: os.tmpdir()`, so it never loads this repo's CLAUDE.md or the user's Claude Code settings.
- `pnpm test` (typecheck first) before every commit, with no network and no subscription. **One end-to-end check** at the end (`pnpm e2e:llm`) on the user's two products.
- Commits: `git -c user.name=heetshah16 -c user.email=shahheet85@gmail.com commit ...` with a `Co-Authored-By:` trailer naming the authoring model.

## Review Focus

1. **The SDK hangs** (no result message, subscription stalled). `generate` must return a `TIMEOUT` at the deadline, not wait forever. → Task 2 test.
2. **A usage limit is hit mid-run.** It must surface as retryable `RATE_LIMIT` with the SDK's text, not as a generic error. → Task 2 test.
3. **The model returns two hooks from one family, or an off-shortlist slug.** One repair call must name the violation verbatim; a second failure returns the violations, not a crash. → Task 5 tests.
4. **The brand name sneaks into the hook,** in any case. → Task 4 test.
5. **Devanagari or Hinglish copy** is counted correctly for word and character limits (code points, whitespace words). → Task 4 test.

```markdown
# Claude Agent SDK — provider reference

**Fetched:** 2026-10-16 from `code.claude.com/docs/en/agent-sdk/structured-outputs` and `…/agent-sdk/typescript`. **Pinned:** `@anthropic-ai/claude-agent-sdk` 0.3.287.

- **`query({ prompt, options })`** returns an async generator of `SDKMessage`. `prompt` is a `string`, or an `AsyncIterable<SDKUserMessage>` for multimodal input.
- **`SDKUserMessage`** = `{ type: 'user', message: MessageParam /* Anthropic SDK */, parent_tool_use_id: string | null, … }`. Images go in `message.content` as Anthropic image blocks: `{ type: 'image', source: { type: 'base64', media_type, data } }`.
- **Options we use:**
  - `model` (alias or full id) and `effort` (`'low'|'medium'|'high'|'xhigh'|'max'`);
  - `systemPrompt` (a string is a custom prompt) and `tools: []`;
  - `maxTurns`, `settingSources: []` (no user, project or local settings, so no CLAUDE.md) and `persistSession: false`;
  - `cwd` and `abortController`;
  - `outputFormat: { type: 'json_schema', schema }`, where the schema is JSON Schema **draft-07** (`z.toJSONSchema(s, { target: 'draft-7' })`).
- **Result message** (`type: 'result'`):
  - `subtype: 'success'` carries `structured_output?`.
  - The error subtypes are `'error_max_turns' | 'error_during_execution' | 'error_max_budget_usd' | 'error_max_structured_output_retries'`, with `errors: string[]`.
  - Both carry `duration_ms`, `is_error`, `total_cost_usd` (an estimate), `usage` (main loop) and `modelUsage` (per model).
- **Treat `subtype: 'success'` without `structured_output` as a failure.**
- A single-shot `query()` **throws after yielding an error result**, so we capture the result before handling the throw.
- **Auth:** the SDK uses the local Claude Code login (subscription) or `ANTHROPIC_API_KEY`. Assistant errors include `authentication_failed`, `oauth_org_not_allowed` and `cloud_credential_error`.
```

```ts
import { tmpdir } from 'node:os';
import { z, type ZodType } from 'zod';
import { query, type Options, type SDKUserMessage } from '@anthropic-ai/claude-agent-sdk';
import {
  ProviderError,
  isRetryable,
  type LLMProvider,
  type LLMRequest,
  type LLMResult,
  type ProviderErrorCode,
  type ProviderResult,
} from '@adforge/core/providers/types';

const P = 'claude-agent-sdk';

export interface ClaudeAgentOptions {
  queryImpl?: typeof query;
  /** Structured output uses an internal turn; 4 leaves headroom without allowing tool loops (tools are off). */
  maxTurns?: number;
  /** Defaults to os.tmpdir() so the SDK never picks up this repo's CLAUDE.md. */
  cwd?: string;
}

export function classify(text: string): ProviderErrorCode {
  if (/usage limit|rate[ _-]?limit|\b429\b|too many requests|overloaded/i.test(text)) return 'RATE_LIMIT';
  if (/authentication_failed|oauth|not logged in|log ?in|credential|unauthori[sz]ed|\b401\b|\b403\b/i.test(text)) return 'AUTH';
  return 'UPSTREAM';
}

const fail = (code: ProviderErrorCode, message: string, raw?: unknown): ProviderResult<never> => ({
  status: 'failed',
  error: new ProviderError(P, code, message, raw),
  retryable: isRetryable(code),
});

export function buildOptions<T>(req: LLMRequest<T>, abort: AbortController, o: ClaudeAgentOptions = {}): Options {
  return {
    model: req.model,
    effort: req.effort,
    systemPrompt: req.system,
    tools: [],
    maxTurns: o.maxTurns ?? 4,
    settingSources: [],
    persistSession: false,

    abortController: abort,
    outputFormat: { type: 'json_schema', schema: z.toJSONSchema(req.schema, { target: 'draft-7' }) as Record<string, unknown> },

export function toUserMessage<T>(req: LLMRequest<T>): SDKUserMessage {
  // Images first, then text (Anthropic guidance for vision prompts).
  const images = req.user.filter((c) => c.type === 'image');
  const texts = req.user.filter((c) => c.type === 'text');
  const content = [
    ...images.map((c) => ({
      type: 'image' as const,
      source: { type: 'base64' as const, media_type: c.mime, data: Buffer.from(c.data).toString('base64') },
    })),
    ...texts.map((c) => ({ type: 'text' as const, text: c.text })),
  ];
  return { type: 'user', parent_tool_use_id: null, message: { role: 'user', content } } as SDKUserMessage;
}

type ResultLike = {
  type: 'result';
  subtype: string;
  structured_output?: unknown;
  errors?: string[];
  duration_ms?: number;
  total_cost_usd?: number;
  usage?: Record<string, number | undefined>;
};

export function mapResult<T>(result: ResultLike, schema: ZodType<T>): ProviderResult<LLMResult<T>> {
  if (result.subtype !== 'success') {
    const text = `${result.subtype}: ${(result.errors ?? []).join('; ')}`;
    return fail(classify(text), `Claude run ended with ${text}`, result);
  }
  if (result.structured_output === undefined) return fail('UPSTREAM', 'Claude run succeeded without structured_output', result);
  const parsed = schema.safeParse(result.structured_output);
  if (!parsed.success) return fail('UPSTREAM', `Claude output failed our schema: ${z.prettifyError(parsed.error)}`, result);
  const u = result.usage ?? {};
  return {
    status: 'done',
    value: {
      value: parsed.data,
      usage: {
        inputTokens: u.input_tokens ?? 0,
        outputTokens: u.output_tokens ?? 0,
        cacheReadTokens: u.cache_read_input_tokens ?? 0,
        cacheCreationTokens: u.cache_creation_input_tokens ?? 0,
      },
    },
    cost: { amountUsd: result.total_cost_usd ?? 0, estimated: true },
    latencyMs: result.duration_ms ?? 0,
  };
}

/** One single-turn, tool-less, schema-constrained call. The only code in AdForge that imports the SDK. */
export class ClaudeAgentProvider implements LLMProvider {
  readonly id = P;
  constructor(private readonly o: ClaudeAgentOptions = {}) {}

  async generate<T>(req: LLMRequest<T>): Promise<ProviderResult<LLMResult<T>>> {
    const abort = new AbortController();
    const timer = setTimeout(() => abort.abort(new Error(`deadline ${req.timeoutMs}ms`)), req.timeoutMs);
    let result: ResultLike | undefined;
    try {
      const prompt = (async function* () {
        yield toUserMessage(req);
      })();
      for await (const m of (this.o.queryImpl ?? query)({ prompt, options: buildOptions(req, abort, this.o) })) {
        if ((m as { type?: string }).type === 'result') result = m as unknown as ResultLike;
      }
    } catch (e) {
      // A single-shot query throws AFTER yielding an error result; prefer the result when we have it.
      if (!result) {
        if (abort.signal.aborted) return fail('TIMEOUT', `Claude call ${req.idempotencyKey} exceeded ${req.timeoutMs}ms`, e);
        const text = (e as Error).message ?? String(e);
        return fail(classify(text), `Claude call ${req.idempotencyKey} failed: ${text}`, e);
      }
    } finally {
      clearTimeout(timer);
    }
    if (!result) return fail(abort.signal.aborted ? 'TIMEOUT' : 'UPSTREAM', `Claude call ${req.idempotencyKey} produced no result message`);
    return mapResult(result, req.schema);
  }
}
```

```ts
import { PIPELINE, type PipelineConfig } from '../config/pipeline';
import { assertVariantDiversity, offShortlist, type Violation } from '../vocab/diversity';
import type { Language } from '../vocab/enums';
import type { Registry } from '../vocab/registry';
import type { Shortlist } from '../vocab/shortlist';
import type { DirectorOutput, DirectorVariant } from './schemas';

const words = (s: string) => s.trim().split(/\s+/).filter(Boolean).length;
const chars = (s: string) => [...s].length;

export function checkVariant(
  v: DirectorVariant,
  ctx: { registry: Registry; brandName: string; language: Language; cfg?: PipelineConfig },
): Violation[] {
  const cfg = ctx.cfg ?? PIPELINE;
  const out: Violation[] = [];
  const add = (rule: Violation['rule'], message: string) => out.push({ rule, message: `variant ${v.variant_no}: ${message}` });

  const beats = ctx.registry.formats.find((f) => f.slug === v.format)?.beats;
  if (beats && v.scenes.length !== beats.length) add('beats', `format "${v.format}" has ${beats.length} beats (${beats.join(' → ')}), got ${v.scenes.length} scenes`);
  if (v.language !== ctx.language) add('language', `language must be "${ctx.language}", got "${v.language}"`);

  const first = v.scenes[0];
  if (first) {
    const { maxWords, maxChars, bannedOpeners } = cfg.hook;
    if (words(first.vo) > maxWords) add('hook_rule', `spoken hook (scene 1 VO) has ${words(first.vo)} words, max ${maxWords} words`);
    if (words(v.hook_text) > maxWords) add('hook_rule', `hook_text has ${words(v.hook_text)} words, max ${maxWords} words`);
    if (chars(first.overlay) > maxChars) add('hook_rule', `on-screen hook has ${chars(first.overlay)} characters, max ${maxChars}`);
    for (const [label, text] of [['hook_text', v.hook_text], ['scene 1 VO', first.vo]] as const) {
      const opener = bannedOpeners.find((b) => text.trim().toLowerCase().startsWith(b.toLowerCase()));
      if (opener) add('hook_rule', `${label} starts with banned opener "${opener}"`);
    }
    const brand = ctx.brandName.trim().toLowerCase();
    if (brand) {
      for (const [label, text] of [['hook_text', v.hook_text], ['scene 1 VO', first.vo], ['scene 1 overlay', first.overlay]] as const) {
        if (text.toLowerCase().includes(brand)) add('hook_rule', `${label} names the brand "${ctx.brandName}"`);
      }
    }
  }

  v.scenes.forEach((s, i) => {
    if (chars(s.overlay) > cfg.hook.maxChars) add('copy', `scene ${i + 1} overlay has ${chars(s.overlay)} characters, max ${cfg.hook.maxChars}`);
    const cap = Math.ceil(s.duration * cfg.timing.voWordsPerSec);
    if (words(s.vo) > cap) add('copy', `scene ${i + 1} VO has ${words(s.vo)} words, max ${cap}`);
    const [lo, hi] = i === 0 ? cfg.timing.hookBeatSec : cfg.timing.beatSec;
    if (s.duration < lo || s.duration > hi) add('timing', `scene ${i + 1} duration ${s.duration}s outside ${lo}–${hi}s`);
  });
  const total = v.scenes.reduce((n, s) => n + s.duration, 0);
  if (Math.abs(total - cfg.timing.totalSec) > 2) add('timing', `total ${total}s, expected about ${cfg.timing.totalSec}s (±2)`);
  return out;
}

export function checkDirection(
  out: DirectorOutput,
  ctx: { registry: Registry; shortlist: Shortlist; brandName: string; language: Language; cfg?: PipelineConfig },
): Violation[] {
  const cfg = ctx.cfg ?? PIPELINE;
  const picks = out.variants.map((v) => ({ hookSlug: v.hook_archetype, formatSlug: v.format }));
  const exp = ctx.shortlist.experimental;
  const offered = {
    formats: [...ctx.shortlist.formats.map((f) => f.slug), ...(exp?.kind === 'format' ? [exp.slug] : [])],
    hooks: [...ctx.shortlist.hooks.map((h) => h.slug), ...(exp?.kind === 'hook' ? [exp.slug] : [])],
  };
  const violations = [
    ...out.variants.flatMap((v) => checkVariant(v, ctx)),
    ...offShortlist(picks, offered),
    ...assertVariantDiversity(picks, ctx.registry, cfg.diversity),
  ];
  const third = out.variants.find((v) => v.variant_no === 3);
  if (exp && third && (exp.kind === 'format' ? third.format : third.hook_archetype) !== exp.slug) {
    violations.push({ rule: 'exploratory', message: `variant 3 must use the exploratory ${exp.kind} "${exp.slug}"` });
  }
  return violations;
}
```

```ts
import { PIPELINE } from '../config/pipeline';
import type { LLMContent, ProviderError } from '../providers/types';
import type { Violation } from '../vocab/diversity';
import type { Language } from '../vocab/enums';
import type { Registry } from '../vocab/registry';
import type { Shortlist } from '../vocab/shortlist';
import { loadPrompt } from './prompts';
import { renderDirectorUser, renderRepair, type ProductInput } from './render';
import { checkDirection } from './rules';
import { directorOutput, type DirectorOutput, type StrategistOutput } from './schemas';
import type { LlmDeps } from './strategize';

export type DirectResult =
  | { status: 'ok'; output: DirectorOutput; repairs: number }
  | { status: 'violations'; output: DirectorOutput; violations: Violation[]; repairs: number }
  | { status: 'failed'; error: ProviderError; retryable: boolean };

export async function direct(
  input: { product: ProductInput; brief: StrategistOutput; shortlist: Shortlist; registry: Registry; language: Language },
  deps: LlmDeps,
): Promise<DirectResult> {
  const cfg = deps.cfg ?? PIPELINE;
  const system = loadPrompt('director').text;
  const schema = directorOutput(input.shortlist, input.language);
  const base: LLMContent = {
    type: 'text',
    text: renderDirectorUser(input.product, input.brief, input.shortlist, input.registry, input.language, cfg),
  };
  const ctx = { registry: input.registry, shortlist: input.shortlist, brandName: input.product.name.split(/\s+/)[0] ?? '', language: input.language, cfg };

  let user: LLMContent[] = [base];
  for (let attempt = 0; ; attempt++) {
    const r = await deps.llm.generate({
      system,
      user,
      schema,
      model: deps.model,
      effort: deps.effort,
      idempotencyKey: attempt === 0 ? deps.idempotencyKey : `${deps.idempotencyKey}:repair${attempt}`,
      timeoutMs: cfg.llm.timeoutMs,
    });
    if (r.status !== 'done') {
      return r.status === 'failed'
        ? { status: 'failed', error: r.error, retryable: r.retryable }
        : { status: 'failed', error: new Error('LLM returned pending') as ProviderError, retryable: true };
    }
    const output = r.value.value;
    const violations = checkDirection(output, ctx);
    if (violations.length === 0) return { status: 'ok', output, repairs: attempt };
    if (attempt >= cfg.diversity.repairPasses) return { status: 'violations', output, violations, repairs: attempt };
    user = [base, { type: 'text', text: renderRepair(violations, output) }];
  }
}
```

```ts
import { readFileSync, readdirSync, statSync } from 'node:fs';
import { extname, join } from 'node:path';
import { REPO_ROOT, parseEnv } from '@adforge/core/config/env';
import { direct } from '@adforge/core/llm/direct';
import { strategize } from '@adforge/core/llm/strategize';
import { Language } from '@adforge/core/vocab/enums';
import { shortlist } from '@adforge/core/vocab/shortlist';
import { openDb } from '@adforge/db/client';
import { loadRegistry } from '@adforge/db/registry';
import { ClaudeAgentProvider } from './adapter';

try {
  process.loadEnvFile(join(REPO_ROOT, '.env'));
} catch (e) {
  if ((e as NodeJS.ErrnoException).code !== 'ENOENT') throw e;
}
const env = parseEnv(process.env);
const MIME = { '.jpg': 'image/jpeg', '.jpeg': 'image/jpeg', '.png': 'image/png', '.webp': 'image/webp' } as const;
const root = join(REPO_ROOT, 'fixtures', 'eval-products');
const products = readdirSync(root).filter((d) => statSync(join(root, d)).isDirectory());
if (products.length < 2) {
  console.error(`Need 2 products in ${root} (product.json + 3–5 photos each). Found ${products.length}.`);
  process.exit(1);
}

const { db, close } = await openDb(env.ADFORGE_DATA_DIR);
const registry = await loadRegistry(db).finally(close);
const llm = new ClaudeAgentProvider();
let ok = true;

for (const slug of products) {
  const dir = join(root, slug);
  const meta = JSON.parse(readFileSync(join(dir, 'product.json'), 'utf8')) as { name: string; price: string; description: string; language: string };
  const language = Language.parse(meta.language);
  const images = readdirSync(dir)
    .filter((f) => extname(f).toLowerCase() in MIME)
    .map((f) => {
      const bytes = readFileSync(join(dir, f));
      if (bytes.byteLength > 5 * 1024 * 1024) throw new Error(`${slug}/${f} is over 5 MB — resize it`);
      return { mime: MIME[extname(f).toLowerCase() as keyof typeof MIME], data: new Uint8Array(bytes) };
    });
  console.log(`\n=== ${slug} (${images.length} photos, ${language}) ===`);

  const t0 = Date.now();
  const s = await strategize({ product: meta, images }, registry, {
    llm, model: env.ADFORGE_LLM_STRATEGIST, effort: env.ADFORGE_LLM_EFFORT_STRATEGIST, idempotencyKey: `e2e:${slug}:strategize`,
  });
  if (s.status !== 'done') { console.error('STRATEGIZE FAILED', s.status === 'failed' ? `${s.error.code} ${s.error.message}` : s.status); ok = false; continue; }
  const brief = s.value.value;
  console.log(`strategist ${((Date.now() - t0) / 1000).toFixed(1)}s ~$${s.cost.amountUsd.toFixed(4)} cacheRead=${s.value.usage.cacheReadTokens}`);
  console.log(`  ${brief.archetype_primary} + ${brief.archetype_secondary} (${brief.confidence}) — ${brief.rationale}`);
  console.log(`  objection: ${brief.core_objection}`);

  const list = shortlist({ archetypePrimary: brief.archetype_primary, archetypeSecondary: brief.archetype_secondary }, registry);
  const t1 = Date.now();
  const d = await direct({ product: meta, brief, shortlist: list, registry, language }, {
    llm, model: env.ADFORGE_LLM_DIRECTOR, effort: env.ADFORGE_LLM_EFFORT_DIRECTOR, idempotencyKey: `e2e:${slug}:direct`,
  });
  console.log(`director ${((Date.now() - t1) / 1000).toFixed(1)}s status=${d.status}${'repairs' in d ? ` repairs=${d.repairs}` : ''}`);
  if (d.status === 'failed') { console.error('  ', d.error.code, d.error.message); ok = false; continue; }
  for (const v of d.output.variants) {
    const fam = (slugs: { slug: string; family: string | null }[], s: string) => slugs.find((x) => x.slug === s)?.family;
    console.log(`  V${v.variant_no} ${v.format}(${fam(registry.formats, v.format)}) + ${v.hook_archetype}(${fam(registry.hooks, v.hook_archetype)}) [${v.visual_treatment}]`);
    console.log(`     hook: "${v.hook_text}"  bet: ${v.strategic_bet}`);
  }
  if (d.status === 'violations') { console.error('  VIOLATIONS:', d.violations.map((x) => x.message)); ok = false; }
}
console.log(ok ? '\nLLM E2E OK' : '\nLLM E2E FAILED');
process.exit(ok ? 0 : 1);
```
